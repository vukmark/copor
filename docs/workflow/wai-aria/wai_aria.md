### **Accessibility with TalkBack: Screen Reader Navigation**

The **Accessibility** section ensures that *all users*, including those relying on **screen readers**, can interact with the application effectively.
It explains how to **enable TalkBack** and how **navigation changes** once it is active, with emphasis on **WAI‑ARIA roles** and **properties** that improve clarity and usability.

---

### **1. Turning On TalkBack**  

TalkBack is Android’s built‑in screen reader that provides spoken feedback for accessibility.

**Steps:**  
Open Settings → Accessibility → TalkBack  
Toggle Use TalkBack → On  
Confirm activation in the dialog box

**2. Basic Navigation with TalkBack**  
Once enabled, TalkBack changes how users interact with apps:

- Single Tap → Highlights/focuses an item (spoken feedback announces it)
- Double Tap → Activates the focused item
- Swipe Right/Left → Moves focus forward/backward through UI elements
- Swipe Up/Down → Changes navigation granularity (e.g., by word, character, control)
- Two‑Finger Swipe → Scrolls lists, pages, or screens
